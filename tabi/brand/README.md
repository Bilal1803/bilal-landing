# tabi / таби

Фирменный знак объединяет строчную t и небольшой лист. Словесный логотип набран авторскими векторными контурами.

- Основной цвет: лайм `#D6FF42`.
- Тёмный цвет: графит `#14161B`.
- Название в интерфейсе и логотипе: `tabi`.
- Русское произношение: «таби».
- Минимальная ширина словесного логотипа: 64 px.
- Свободное поле вокруг: не меньше высоты точки над i.
- Не растягивать, не наклонять и не добавлять обводку.
- Для тёмного фона использовать `tabi-wordmark-white.svg`, для одного цвета — `tabi-wordmark-mono.svg`.

SVG масштабируются без потери качества. PNG-версии и значки приложения подготовлены из тех же векторных оригиналов.
